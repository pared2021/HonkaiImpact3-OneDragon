# 崩坏三模板图片库

此目录存放用于 OpenCV 模板匹配的游戏 UI 截图模板。

## 目录结构

- `main_menu/` - 主界面相关模板
- `battle/` - 战斗界面相关模板
- `daily/` - 日常任务界面模板
- `expedition/` - 远征界面模板
- `supply/` - 补给(抽卡)界面模板
- `common/` - 通用按钮模板 (确认/取消/关闭等)

## 使用方法

1. 在游戏中截取需要识别的 UI 元素
2. 裁剪出目标区域，保存为 PNG 格式
3. 放入对应的子目录中
4. 命名规范: `{功能}_{状态}.png`，例如 `btn_confirm_normal.png`

## 注意事项

- 模板图片应为游戏实际分辨率下的截图
- 避免包含动态变化的内容 (如数字、进度条)
- 对于有透明区域的模板，需同时提供 mask 图片 (同名_mask.png)
